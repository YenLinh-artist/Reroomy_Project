## Specialized Furniture Icon Sources

### Primary UI icon library
- Lucide Icons: https://lucide.dev/icons/
- Use Lucide for navigation, actions, status indicators, account controls, and general interface icons.

### Specialized furniture and interior icons
When Lucide does not provide a suitable furniture or interior-specific icon, search these sources in order:

1. SVG Repo Furniture Line Icons: https://www.svgrepo.com/collection/furniture-line-icons/
2. IconScout Indoor Furniture: https://iconscout.com/icon-pack/indoor-furniture
3. IconScout Interior Design: https://iconscout.com/icon-pack/interior-design
4. Iconfy: https://icon-sets.iconify.design/
### Search and selection rules
- Search for a semantically appropriate icon before creating any custom SVG.
- Prefer simple monochrome outline icons that match RE:ROOM's established visual language.
- Prioritize consistent stroke width, rounded or clean geometry, clear silhouettes, and readability at small sizes.
- Do not mix filled, isometric, colorful, and outline icon styles in the same icon group.
- Verify the license and attribution requirements before using downloaded assets.
- Do not assume that an icon is free to download or use commercially just because it is visible on a website.

### Asset management
- Save approved downloaded SVG assets locally in `store/static/store/icons/`.
- Use descriptive, consistent filenames, for example `sofa.svg`, `bed.svg`, `wardrobe.svg`, `desk.svg`, and `floor-lamp.svg`.
- Maintain an icon manifest at `docs/ICON_MANIFEST.md` recording each icon's semantic name, source URL, license, and usage.
- Reuse approved local assets instead of searching for or recreating the same icon again.
- If no suitable icon is found, report the missing icon and suggest alternatives before creating a custom icon.
